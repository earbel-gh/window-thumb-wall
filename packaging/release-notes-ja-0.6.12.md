# 変更点
- 特定のウィンドウを登録し、復元できます。元のウィンドウが閉じても、手動で保存した枠は同じ位置に残り、あとで置き換え先を選べます。
- 復元時に保存済みのウィンドウハンドルを使う場合は、タイトルとアプリの識別情報を確認します。ブラウザーの WhatsApp では、未読件数を除いてタイトルを照合します。
- 置き換え先が現在も有効なことを確認し、新しいサムネイルの登録が成功してから枠を切り替えます。
- Windows の通知購読エラーが発生した場合は、定期的に通知を確認して通知表示を復旧できます。確認の間に消えた通知は表示できない場合があります。
- 設定画面は通知の状態表示が長くなると縦に広がり、閉じるボタンまで表示されます。
