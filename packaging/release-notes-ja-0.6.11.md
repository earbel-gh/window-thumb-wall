# Changes
- 特定の Windows 通知イベント購読 RPC エラーに対し、状態を表示するスナップショット専用の復旧経路と上限付きの再試行を追加しました。初期通知の基準状態は維持されますが、スナップショット間に表示されて消える通知は検出できない場合があります。
- WhatsApp のブラウザータイトル照合では、先頭の未読件数を取り除くようにしました。未読件数が変わっても保存済みタブを照合しやすくなります。
- 手動で保存したセルは、元ウィンドウが閉じても同じ位置に残ります。破棄後に再利用された HWND は、新しいウィンドウの観測ライフタイムとして扱います。
- 開いているウィンドウを置き換え先に選ぶと、現在も有効なウィンドウか確認し、新しい DWM サムネイル登録が成功した後でセルを切り替えます。
