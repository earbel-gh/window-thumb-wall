# 変更点

- 特定のウィンドウを登録し、復元できます。元のウィンドウが閉じても、手動で保存した枠は同じ位置に残り、あとで置き換え先を選べます。
- 復元時はタイトルとアプリの識別情報を確認します。ブラウザーの WhatsApp では未読件数を除いてタイトルを照合します。Windows が閉じたウィンドウのハンドルを再利用した場合は、新しいウィンドウとして扱います。
- 置き換え先が現在も有効であることを確認し、新しいサムネイルの登録が成功してから枠を切り替えます。
- 特定の Windows 通知購読エラーが起きた場合は、定期的に通知を確認して表示を復旧します。復旧中の状態は画面に表示し、確認の間に消えた通知は表示できない場合があります。
- 設定画面は通知の状態表示が長くなると縦に広がり、閉じるボタンまで表示されます。
